## What counts as a citation

A citation is an **external** work that attributes a number, dataset or finding
to Harpd and links back to it. Specifically:

| Tier | What it looks like | Counted here? |
|---|---|---|
| 1 | External project consumes Harpd data | No — that is [adoption](adoption.md) |
| 2 | External project links to Harpd | No — that is a backlink |
| 3 | **External project cites Harpd as a source** | **Yes** |
| 4 | AI agent retrieves Harpd data | No — that is retrieval |
| 5 | **AI answer cites Harpd** | **Yes** |

Tiers 3 and 5 are recorded in this file. Tiers 1 and 2 are recorded in
[adoption.md](adoption.md). Tier definitions live in [metrics.md](metrics.md).

## What is explicitly not counted

- Harpd's own repositories, READMEs, docs or blog posts.
- Forks that were never used.
- Estimated, projected or modelled citation counts.
- Anything that cannot be opened at a public URL and checked.

## How to get listed

If you have cited Harpd data, open a
[data citation issue](https://github.com/harpd-dev/harpd-ai-datasets/issues/new?template=integration.yml)
or a PR editing this file. Include the citing work, the dataset cited, the
citation context and a public URL. Entries are verified before being added.

## Citation formats

**BibTeX**

```bibtex
@dataset{harpd_ai_datasets,
  author    = {Harpd},
  title     = {Harpd AI Datasets},
  year      = {2026},
  publisher = {Harpd},
  url       = {https://harpd.com/data/},
  license   = {CC BY 4.0}
}
```

**APA style**

> Harpd. (2026). *Harpd AI Datasets*. https://harpd.com/data/ (CC BY 4.0)

**Machine-readable** — [`CITATION.cff`](../CITATION.cff), which GitHub renders
as a citation block on the repository page.

**Attribution string (required by CC BY 4.0)**

```
Data from Harpd (https://harpd.com/)
```

Always cite the **dataset**, not the repository, and prefer a pinned release tag
(`v2026.9`) so the citation resolves to an immutable snapshot.
