# Harpd GitHub Ecosystem

An audit of every repository in the [`harpd-dev`](https://github.com/harpd-dev)
organization, and how it fits the path:

```text
Harpd Data → Research → Benchmarks → Explorer → MCP → External adoption → Citation
```

**Audited:** 2026-09-16 · **Repositories:** 26 (23 public, 3 private)

This file is regenerated by hand after each structural change. It only lists
repositories that actually exist — no planned or placeholder repos.

## Metadata quality gate

Checked on every audit. A repository fails the gate if it is missing a
description, has no topics, has no license, or links to a repository that does
not exist.

| Check | Result (2026-09-16) |
|---|---|
| Public repos missing a description | **0** (was 1 — `agent-budget-policy-go`) |
| Public repos with zero topics | **0** (was 3 — `harpd-discovery-dataset`, `agent-budget-policy-go`, `.github`) |
| Public repos with no license file | 0 |
| Cross-links pointing at non-existent repos | 0 |
| Organization profile rendering | **Fixed** — README was at repo root; GitHub only renders `.github/profile/README.md`, so `github.com/harpd-dev` was blank. Moved. |

## Standing rules

1. No bought stars, star exchanges, fake contributors, fake issues or fake forks.
2. No spam on Reddit / Hacker News, no mass meaningless PRs.
3. Harpd's own repositories are **never** counted as external adoption.
4. No fabricated citations or usage numbers.
5. Rank Points are promotional placement and are never described as editorial quality.
6. Every published figure carries a dataset, a timestamp and a methodology.
