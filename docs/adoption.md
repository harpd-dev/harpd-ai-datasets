## How adoption is counted

Adoption = a **third-party project** that genuinely consumes Harpd data
(via raw.githubusercontent.com, a fork, or a release tag) and references Harpd.
GitHub stars on *this* repo are **not** adoption by themselves — see
[metrics.md](metrics.md).

## How to get listed

If you built something with Harpd data, open an
[integration issue](https://github.com/harpd-dev/harpd-ai-datasets/issues/new?template=integration.yml)
or a PR editing this file. Include: project name, type, the dataset(s) used,
and a public URL. Listings are verified before being added.
