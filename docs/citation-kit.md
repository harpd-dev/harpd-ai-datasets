# Citation kit

Copy-paste what you need. Always cite the **dataset**, not the repository, and
prefer a pinned release tag so the citation resolves to an immutable snapshot.

## Attribution string (required by CC BY 4.0)

```text
Data from Harpd (https://harpd.com/)
```

## BibTeX

```bibtex
@dataset{harpd_ai_datasets,
  author    = {Harpd},
  title     = {Harpd AI Datasets},
  year      = {2026},
  publisher = {Harpd},
  url       = {https://harpd.com/data/},
  license   = {CC BY 4.0}
}
```

## APA

> Harpd. (2026). *Harpd AI Datasets*. https://harpd.com/data/ (CC BY 4.0)

## Pinned-release BibTeX (recommended)

```bibtex
@dataset{harpd_ai_datasets_2026_9,
  author    = {Harpd},
  title     = {Harpd AI Datasets},
  year      = {2026},
  publisher = {Harpd},
  url       = {https://github.com/harpd-dev/harpd-ai-datasets/releases/tag/v2026.9},
  license   = {CC BY 4.0}
}
```
