# Integration Candidates

Candidate types of open-source projects that could **legitimately consume**
Harpd AI Datasets. These are *opportunities to pursue*, **not** claims that
they already use the data. No auto-spam PRs — reach out only where a genuine
fit exists.

## Candidate categories

| Candidate type | Why relevant | Best-fit dataset | Integration idea |
|---|---|---|---|
| AI directories / aggregators | Need a structured product catalog | Products, AI Agent Index | Mirror Harpd products into a searchable directory. |
| AI ranking dashboards | Want a credible rank source | Rankings (overall/monthly/weekly) | Plot rank-point trends over monthly snapshots. |
| AI comparison tools | Compare products across categories | Products, AI Tools Index | Build side-by-side product comparison pages. |
| AI agent frameworks | Catalog agents they can call | AI Agent Index | Index agents as callable tools / MCP servers. |
| AI research projects | Need evidence-backed claims | Evidence, Research Index | Cite ranking methodology in a paper or report. |
| AI benchmark projects | Need a baseline corpus | Products, AI Market Index | Use category share as a market baseline. |
| MCP server registries | Want a tool/data catalog | AI Agent Index, Products | Expose Harpd data as an MCP resource. |
| LLM tooling / RAG | Need fresh AI-product context | All | Ingest datasets as retrieval corpus for agents. |

## How to pursue (manually, with consent)

1. Identify a real project in one of the categories above.
2. Confirm it genuinely needs structured AI-product / ranking data.
3. Open an issue or discussion **offering** the dataset — never a bot PR.
4. If they adopt it, record them in [adoption.md](adoption.md).

## Notes

- Always link back to the canonical source: https://harpd.com/data/
- Attribute: `Data from Harpd (https://harpd.com/)` (CC BY 4.0).
- Prefer pointing projects at a **release tag** (`v2026.9`) for stability.
